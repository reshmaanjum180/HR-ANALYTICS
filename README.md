
# 📊 HR Analytics Dashboard | Power BI

An interactive **HR Analytics Dashboard** built using **Power BI** to analyze employee salary distribution, department performance, and job role insights. This project demonstrates the complete Business Intelligence workflow—from data creation and cleaning to dashboard visualization.

---

## 📌 Project Overview

The objective of this project is to provide HR managers and business stakeholders with meaningful insights into workforce data through interactive visualizations.

The dashboard enables users to:
- Analyze salary distribution across departments
- Compare salaries by job title
- Monitor department performance ratings
- Filter data dynamically using slicers
- Make data-driven HR decisions

---

## 🛠️ Tech Stack

- **Microsoft Excel** – Data creation and storage
- **SQL** – Data cleaning and preprocessing
- **Power BI Desktop** – Data modeling, DAX calculations, and dashboard visualization

---

## 📂 Workflow

1. **Data Creation**
   - Created a sample HR dataset in Microsoft Excel containing employee information such as:
     - Employee ID
     - Department
     - Job Title
     - Salary
     - Performance Rating
     - Other HR-related attributes

2. **Data Cleaning (SQL)**
   - Removed duplicate records
   - Handled missing values
   - Standardized department and job title names
   - Improved data consistency
   - Prepared the dataset for reporting

3. **Power BI Dashboard Development**
   - Imported the cleaned dataset
   - Created relationships and data model
   - Built interactive visuals
   - Added slicers for dynamic filtering
   - Designed an easy-to-understand HR dashboard
